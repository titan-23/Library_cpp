# cpu_timer.cpp

[titan_cpplib/ahc/cpu_timer.cpp](../../titan_cpplib/ahc/cpu_timer.cpp) の `CpuTimer` は、プロセスの CPU 時間で経過時間を計る。使い方は `titan23::Timer` と同じである。

## Timer との違い

`Timer` は実時間 (wall clock) で計る。`CpuTimer` との違いは次のとおり。

- 他のプロセスにコアを取られて待っていた時間を含まない。
- ローカルでテストケースを並列に実行するとき、実時間で計るより挙動がジャッジに近づく。
- ジャッジでは 1 プロセスがコアを占有するので、CPU 時間は実時間とほぼ等しい。時間の予算はそのまま使える。
- 入出力の待ちと起動の時間は CPU 時間に含まれない。実時間の制限時間に対しては、従来どおりの余裕を取る。

## 注意

- キャッシュやメモリ帯域の競合で 1 命令あたりの実効速度が落ちる分は、CPU 時間にも乗る。
- 並列数が物理コア数以下でも遅くなる分は、CPU 時間で計っても補正できない。
- マルチスレッドでは全スレッドの合計になる。このライブラリの用途では単一スレッドを前提とする。
- Windows 以外では、時刻の取得は clock_gettime のシステムコールで行う。実時間の取得より少し重く、数十から数百 ns かかる。
- 世代ごとに数回呼ぶ程度なら、取得の重さは無視できる。候補ごとに呼ぶ用途には使わない。

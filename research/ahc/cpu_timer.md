# cpu_timer.cpp

[titan_cpplib/ahc/cpu_timer.cpp](../../titan_cpplib/ahc/cpu_timer.cpp) の `CpuTimer` は、プロセスの CPU 時間で経過時間を計測します。使用方法は `titan23::Timer` と同じです。

## Timer との違い

`Timer` は実時間 (wall clock) で計測します。`CpuTimer` との違いは次のとおりです。

- 他のプロセスがコアを使用している間に待機していた時間を含みません。
- ローカルでテストケースを並列に実行するときは、実時間で計測する場合より挙動がジャッジに近くなります。
- ジャッジでは 1 プロセスがコアを占有するため、CPU 時間は実時間とほぼ等しくなります。時間の配分はそのまま使用できます。
- 入出力の待ち時間と起動時間は CPU 時間に含まれません。実時間の制限時間に対しては従来どおりの余裕を確保します。

## 注意

- キャッシュやメモリ帯域の競合で 1 命令あたりの実効速度が低下すると、その分だけ CPU 時間も増加します。
- 並列数が物理コア数以下でも遅くなる分は、CPU 時間で計測しても補正できません。
- マルチスレッドでは全スレッドの合計になります。このライブラリの用途では単一スレッドを前提とします。
- Windows 以外では時刻の取得を clock_gettime のシステムコールで行います。実時間の取得より処理時間が少し長く、数十から数百 ns かかります。
- 世代ごとに数回呼び出す程度であれば、取得にかかる時間を考慮する必要はありません。候補ごとに呼び出す用途には使用しないようにします。

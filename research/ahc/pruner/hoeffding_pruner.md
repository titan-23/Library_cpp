# hoeffding_pruner.cpp

## コンストラクタの引数

- `max_seeds` は評価に使用するシードの最大数です。
- `score_range` は 1 つのシードでのスコア差の最大幅です。理論上の上限から下限を引いた値を渡します。
- `delta` は最良の候補を誤って枝刈りする確率の上限です。有意水準に相当し、例えば 0.05 を渡します。
- `min_samples` は枝刈りの判定を開始するために必要な共通シードの最小数です。
- `is_minimize` には、最小化問題であれば true、最大化問題であれば false を渡します。

## メソッドの引数と戻り値

- `report(seed, score)` の `seed` は評価に使用したシード値で、`score` は評価関数が返したスコアです。
- `should_prune()` は、現在のパラメータが劣っていて枝刈りすべきときに true を返します。評価を続けるべきときは false を返します。
- `next_param(was_pruned)` には、途中で枝刈りして終了した場合は true、最後まで評価した場合は false を渡します。

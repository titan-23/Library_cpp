# wilcoxon_pruner.cpp

## 概要

- パラメータ探索の枝刈りに使用します。
- 同じシードの集合での評価スコアを Wilcoxon 符号順位検定で比較します。
- 現在のパラメータが既知の最良のパラメータより有意に劣るとき、評価を早期に打ち切ります。

## 使用方法

パラメータ 1 つにつき、次の順に呼び出します。

1. シードごとに評価し、`report(seed, score)` で報告します。
2. 区切りで `should_prune()` を呼び出します。true であれば以降の評価を中止します。
3. 評価を終えたら `next_param(was_pruned)` を呼び出し、次のパラメータへ進みます。

- 最良のパラメータの更新は `next_param` の中で自動的に行われます。
- 最後まで評価し、かつ平均が改善したときだけ最良のパラメータを置き換えます。

## コンストラクタの引数

- `max_seeds` は評価に使用するシードの最大数です。内部の配列を事前に確保するときの大きさとして使用します。
- `p_threshold` は枝刈りを判定する有意水準です。
- `min_samples` は枝刈りの判定を開始するために必要な共通シードの最小数です。
- `is_minimize` には、最小化問題であれば true、最大化問題であれば false を渡します。

## メソッドの引数と戻り値

- `report(seed, score)` の `seed` は評価に使用したシード値で、`score` は評価関数が返したスコアです。
- `should_prune()` は、現在のパラメータが劣っていて枝刈りすべきときに true を返します。評価を続けるべきときは false を返します。
- `next_param(was_pruned)` には、途中で枝刈りして終了した場合は true、最後まで評価した場合は false を渡します。

# bit_vector.cpp

## 内部表現

- 64 bit ごとに、ビット列 `bits` とその直前までの 1 の個数 `acc` を 1 つの `Block` にまとめて保持します。
- rank は 1 つのブロックだけを参照します。ビット列と累積値が隣接しているため、参照するキャッシュラインは 1 本だけです。

## 関数で構築するコンストラクタ

- `BitVector(n, bit_of)` は、i 番目のビットが `bit_of(i)` である長さ n のビット列を作成し、build まで実行します。計算量は O(n) です。
- 64 bit ずつレジスタ上で組み立ててから格納します。set を繰り返す方法より分岐と書き込みが少なくなります。

# dynamic_lazy_segment_tree.cpp

## 前提

- 管理範囲は [0,N) である。値が一様な区間の境界を Patricia 木で管理する。
- composition(f,g) は g の後に f を適用する作用である。
- pow(x,k) は x を k 個結合した値を返し、pow(x,0)==e() を満たす。
- T の等値比較は不要である。値が等しくなった隣接区間は自動では結合しない。

## 計算量の前提

- N は列の長さ、M は保持ノード数、M_other はコピー元またはムーブ元のノード数を表す。
- T と F の演算、コピー、ムーブ、破棄と、pow、述語の評価は O(1) とする。
- ノード追加を含む計算量は償却計算量である。

## ノード数

- 区間数 B に対してノード数は 2B-1 個である。B=0 ならノード数は 0 個である。
- 同じ境界への更新と問い合わせはノードを追加しない。
- 保持ノード数の上限は 2^31-1 個である。

## ノードの表現

- 葉と分岐を別々のプールに保持する。葉には 1 要素の値と区間長だけを持たせる。
- 分岐の右端は保存せず、下降時に親から持ち回る。
- 型の整列条件に合わせて小さい分岐配置を選び、余白があれば分岐ビットを保持する。
- ノード番号は 0 が欠損、奇数が葉、正の偶数が分岐を表す。右の子の番号の最上位ビットを遅延フラグに使う。

## inner_prod の実装

- l と r が別の子に分かれたあとは、左端側と右端側の経路を同じループで下り、2 つの経路の読み出しを重ねる。
- inner_prod は呼び出し元のループに展開されると、測定では 5% ほど遅くなった。そのため `[[gnu::noinline]]` で展開させない。

## 探索スタック

- max_right と min_left の探索スタックは、添字型のビット幅だけ領域を確保する。
- 同時に生存する探索状態は最大 O(logN) 個である。
- SearchStack は F の既定構築を要求せず、必要な状態だけを構築する。
- SearchStack の破棄にかかる O(P) の P は、保存している探索状態数である。

# hash_set.cpp

## 方式

- 開番地法の線形探査で鍵を保持します。0 は空きを表す値として使用し、鍵 0 の有無は別の変数 has_zero で表します。
- 探査は表の末尾で折り返さず、末尾の余白へ続けます。余白の末尾の WINDOW 個は常に空のまま維持します。
- 要素数が容量の半分を超えた場合は容量を 2 倍にします。
- 測定記録は [test/ds/benchmark/hash_set_benchmark.md](../../test/ds/benchmark/hash_set_benchmark.md) にあります。

## contains

- 連続する WINDOW 個の鍵を simd_equal_bits でまとめて比較し、分岐予測の失敗を減らします。
- 探査の開始位置から鍵の位置までの間に空きはありません。このため、比較する WINDOW 個の範囲に鍵があれば、その範囲の空きの有無によらず鍵が見つかったと判定できます。
- 余白の末尾の WINDOW 個は常に空であるため、比較する範囲は余白を含む表の外に出ません。
- always_inline でインライン展開を強制します。SSE2 だけの環境では比較の命令が増え、-O2 ではインライン展開されなくなるためです。

## 挿入

- 挿入の探査では鍵を 1 個ずつ比較します。
- 命令数が少ないほど、表が大きい場合に複数の操作の読み出しが並行して実行され、高速になります。

## ハッシュ関数 home

- 128 bit の積の上位と下位の xor を求めます。HashDict と同じ方式です。
- 128 bit の値を変数に格納すると、GCC 12 は SIMD を使用する関数で積をスタック経由で再度読み込む場合があります。
- 上位と下位を別の式で求めると乗算は 2 回になりますが、スタックを経由する場合より高速です。

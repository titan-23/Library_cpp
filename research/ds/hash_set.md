# hash_set.cpp

## 方式

- 開番地法の線形探査で鍵を持つ。0 を空きの印に使い、鍵 0 は別の変数 has_zero で持つ。
- 探査は表の末尾で折り返さず、末尾の余白へ続ける。余白の最後の WINDOW 個は常に空に保つ。
- 要素数が容量の半分を超えたら容量を 2 倍にする。
- 測定記録は [test/ds/benchmark/hash_set_benchmark.md](../../test/ds/benchmark/hash_set_benchmark.md) にある。

## contains

- 連続する WINDOW 個の鍵を simd_equal_bits でまとめて比べ、分岐予測の失敗を減らす。
- 鍵より前に空きはない。このため、窓に鍵があれば、窓の中の空きの有無によらず見つかったとしてよい。
- 最後の WINDOW 個は常に空なので、窓は表の外に出ない。
- always_inline でインライン展開を強制する。SSE2 だけの環境では比較の命令が増え、-O2 だとインライン展開されなくなるためである。

## 挿入

- 挿入の探査は 1 個ずつ比べる。
- 命令数が少ないほど、表が大きいときに複数の操作の読み出しが重なって速い。

## ハッシュ関数 home

- 128 bit の積の上位と下位を xor する。HashDict と同じ方式である。
- 128 bit の値を変数に置くと、GCC 12 は SIMD を使う関数で積をスタック経由で読み直すことがある。
- 上位と下位を別の式で求めると乗算は 2 回になるが、スタックを経由するより速い。

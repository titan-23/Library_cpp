# simple_tabulation_hash_dict.cpp

## 計算量の保証

- 入力列が内部乱数と独立なら、負荷率 1/2 で検索と更新は期待償却 O(1) である。
- この保証は、tab の各値が独立な一様乱数であるモデルに基づく。
- clear と values と items は O(cap) である。

## 表の構成

- 衝突したときは次の位置を順に調べる。
- erase を持たないので、key == 0 を空きスロットとして使う。
- 鍵 0 の値は vals[cap] に置き、有無は has_zero で持つ。
- 要素数の 2 倍が cap を超えると、cap を 2 倍にして入れ直す。
- get_pos と pos の結果は次の変更操作まで有効である。

## ハッシュ関数の乱数

- tab の各値は、容量に必要な下位 bit だけを生成する。
- 拡張時は独立な新しい bit plane を加える。tab の各値に、独立な乱数 bit を 1 つずつ上位に足す。

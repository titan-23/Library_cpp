# simple_tabulation_hash_dict.cpp

## 計算量の保証

- 入力列が内部乱数と独立であれば、負荷率 1/2 で検索と更新は期待償却 O(1) です。
- この保証は tab の各値が独立な一様乱数であるモデルに基づきます。
- clear と values と items は O(cap) です。

## 表の構成

- 衝突した場合は次の位置を順に調べます。
- erase がないため、key == 0 を空きスロットとして使用します。
- 鍵 0 の値は vals[cap] に格納し、有無は has_zero で保持します。
- 要素数の 2 倍が cap を超えると、cap を 2 倍にして全要素を再挿入します。
- get_pos と pos の結果は次の変更操作まで有効です。

## ハッシュ関数の乱数

- tab の各値については、容量に必要な下位 bit だけを生成します。
- 拡張時は独立な新しい bit plane を追加します。tab の各値の上位に、独立な乱数 bit を 1 つずつ加えます。

# wavelet_matrix_2d_min.cpp

## 概要

- オフラインの 2 次元点集合で、長方形内の重みの最小値と最大値を求める。
- テンプレート引数 `T` は座標の型、`W` は重みの型である。

## 点と重みの扱い

- 同じ座標へ複数回登録した点は、別々の点として扱う。
- 重みが同じ場合、`range_argmin` と `range_argmax` は先に登録した点を返す。
- 各重みは `minus_inf < weight < inf` を満たすことを前提とする。

## 使用例

- 点 `(x, y, weight)` の列 `[(0, 1, 7), (2, 3, 4)]` の全体で、`range_argmin` は `(4, 2, 3)` を返す。
- 同じ列の全体で、`range_argmax` は `(7, 0, 1)` を返す。

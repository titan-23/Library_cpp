# wavelet_matrix_2d_sum.cpp

## 概要

- オフラインの 2 次元点集合で、長方形内の点の個数と重みの総和を求めます。
- テンプレート引数 `T` は座標の型、`W` は重みの型です。

## 点の扱い

- 同じ座標へ複数回登録した点は、別々の点として集計します。
- 同じ `y` の点を途中まで採用する場合は `x` の昇順に選択します。
- 同じ `x` の点は登録順に選択します。

## 使用例

- 点 `(x, y)` の列 `[(0, 5), (1, 2), (2, 2)]` で `kth_y(0, 3, 1)` は `2` を返します。
- 点 `(x, y, weight)` の列 `[(0, 5, 4), (1, 2, 3), (2, 7, 6)]` で `sum_k_smallest_y(0, 3, 2)` は `7` を返します。
- 同じ列で `sum_k_largest_y(0, 3, 2)` は `10` を返します。

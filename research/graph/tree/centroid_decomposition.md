# centroid_decomposition.cpp

## solve(func) の動作

- 重心分解木 T を根 C から葉に向かってたどり、各頂点 v で func(v, banned) を呼び出します。
- 第 2 引数の banned は、v より上位で既に中心として使用した頂点を true にした配列です。
- v の処理の後に v 自身も true にしてから、T の子へ降ります。
- func が呼ばれた時点では、元の木 G 上で banned が false の頂点だけを通って v から到達できる範囲が、v を中心として今回処理すべき部分木です。
- 使用方法は `cd.solve([&] (int v, const vector<bool>& banned) { ... });` です。

## func を実装するときの注意

- 部分木を探索するときは元の木 G の隣接リストをたどります。
- banned が true の頂点は訪問してはいけません。その頂点へは進まず、その方向の探索を打ち切ります。
- 元の木と重心分解木を取り違えないようにします。
- v をまたぐパスは、v だけのパス、v を端点とするパス、v を端点としないパスなどに場合分けして考えます。
- パスの重複に注意します。
- v をまたぐパスの個数を求めるときは、v の子の部分木ごとに独立に集計し、それぞれの集計が終わってから組み合わせます。
- 同じ子の部分木に属する 2 頂点を結ぶパスは v をまたぎません。全てをまとめて集計すると、重複や集計の誤りが発生します。

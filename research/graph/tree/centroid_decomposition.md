# centroid_decomposition.cpp

## solve(func) の動き

- 重心分解木 T を根 C から葉に向かってたどり、各頂点 v で func(v, banned) を呼ぶ。
- 第 2 引数の banned は、v より上位で既に中心として使った頂点を true にした配列である。
- v の処理の後に v 自身も true にしてから、T の子へ降りる。
- func が呼ばれた時点で、元の木 G 上で v からたどれて banned が false の範囲が、v を中心として今回処理すべき部分木である。
- 使い方は `cd.solve([&] (int v, const vector<bool>& banned) { ... });` である。

## func を書くときの注意

- 部分木を探索するときは、元の木 G の隣接リストをたどる。
- banned が true の頂点は見てはいけない。踏み込まずに引き返す。
- 元の木と重心分解木を取り違えない。
- v をまたぐパスは、v だけ、v を端点とする、v を端点としない、などに場合分けして考える。
- パスの重複に注意する。
- v をまたぐパスを数えるときは、v の子部分木ごとに独立に集計し、それぞれを集計してから組み合わせる。
- 同じ子部分木に属する 2 頂点の対は v をまたがない。全てまとめて集計すると、重複や数え誤りが起きる。

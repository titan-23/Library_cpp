# kruskal_reconstruction_tree.cpp

## 頂点の番号

- 元の頂点は葉 [0, N) に配置し、合併で作成する頂点は [N, node_count()) に配置します。
- 親の番号は子の番号より大きくなります。
- グラフが非連結であれば森になります。

## 計算量

- 構築は O(M log M + M alpha(N) + N log N) 時間です。
- 構築後に保持する領域は O(N log N) です。
- コンストラクタは辺をコピーするため、O(M) の領域を使用します。

## 重みの型

- T はデフォルト構築、コピー、< による大小比較ができる型です。
- 数値の番兵は使用しません。

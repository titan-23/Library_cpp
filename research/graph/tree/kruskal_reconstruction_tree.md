# kruskal_reconstruction_tree.cpp

## 頂点の番号

- 元の頂点は葉 [0, N) に置き、合併で作る頂点は [N, node_count()) に置く。
- 親の番号は子の番号より大きい。
- グラフが非連結なら森になる。

## 計算量

- 構築は O(M log M + M alpha(N) + N log N) 時間である。
- 構築後に保持する領域は O(N log N) である。
- コンストラクタは辺をコピーするので、そのために O(M) の領域を使う。

## 重みの型

- T はデフォルト構築、コピー、< による大小比較ができる型である。
- 数値の番兵は使わない。

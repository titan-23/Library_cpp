# link_cut_tree_subtree.cpp

## 計算量

- op と inv は可換群をなす必要がある。
- 群演算を O(1) とすると、各操作は償却 O(log n) である。
- get は O(1) である。
- 構築、オブジェクトのコピー、メモリは O(n) である。
- これらは 1 回の操作の最悪時間を保証するものではない。

## splay

- 遅延させる操作は反転だけである。
- g より上に未伝播の反転があると、回転する部分木全体が左右反転する。このため g, p, v をその場で push すれば足りる。
- 通常の zig、zig-zig、zig-zag の各段を、祖先へのパスを 2 度たどらずに行う。

## link

- c は表現木の根なので、splay した時点で左の子を持たない。
- p に付けるとき、c の優先パス上の子孫は右の子に残したままでよい。

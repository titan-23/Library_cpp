# link_cut_tree_subtree.cpp

## 計算量

- op と inv は可換群をなす必要があります。
- 群演算を O(1) とすると、各操作は償却 O(log n) です。
- get は O(1) です。
- 構築、オブジェクトのコピー、メモリは O(n) です。
- これらは 1 回の操作の最悪時間を保証するものではありません。

## splay

- 遅延させる操作は反転だけです。
- g より上に未伝播の反転があると、回転する部分木全体が左右反転します。このため各回転の直前に g, p, v を push すれば十分です。
- 通常の zig、zig-zig、zig-zag の各ステップを、祖先へのパスを 2 度たどらずに実行します。

## link

- c は表現木の根であるため、splay した時点で左の子はありません。
- p に接続するとき、c の優先パス上の子孫は右の子に残したままで問題ありません。

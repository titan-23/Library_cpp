# edit_distance_query.cpp

## 概要

- EditDistanceQuery は、固定した 2 つの列 s, t の任意の半開区間同士の編集距離を求めます。挿入、削除、置換のコストはそれぞれ 1 です。
- 入力列を更新する場合は EditDistanceQuery を再構築する必要があります。
- 決定的な LCE を使用するため、ハッシュの衝突は発生しません。

## 構築

- 文字列か、const な size() と添字アクセスに対応した列を受け取ります。
- 要素の < は、等値比較と整合する狭義弱順序 (strict weak ordering) である必要があります。
- |s|+|t|+1 <= INT_MAX である必要があります。INT_MAX を超える場合は length_error を送出します。
- 構築後は元の列を変更しても破棄してもかまいません。
- N = |s|+|t|+1 とします。要素の比較と添字アクセスが O(1) の場合、前処理は O(N log N) 時間・空間です。
- s と t の要素をまとめて座標圧縮し、1 以上の値にします。0 は s と t の区切りだけに使用します。

## クエリ

- distance は距離 d に対して O((d+1)^2) 時間、O(d+1) 作業空間です。
- distance_bounded と within は、k >= 0 のとき O((k+1)^2) 時間、O(k+1) 作業空間です。
- within は、k が両区間の長さの最大値以上の場合は距離を計算せずに true を返します。

## bounded_impl

- prev[d] は、編集回数を固定したときに対角線 d = x-y 上で一致部分を進み終えた最も遠い x です。添字は prev_l だけずらして格納します。
- LCE が指定された区間の外まで続く場合も、区間の端で打ち切ります。
- 残りの編集回数では終点の対角線に戻ることができない状態は除外します。
- 端を越える遷移は、同じ対角線上の端に切り詰めます。これにより、「高々 cost 回」で到達できる最も遠い点を維持します。

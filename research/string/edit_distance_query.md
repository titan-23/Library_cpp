# edit_distance_query.cpp

## 概要

- EditDistanceQuery は、固定した 2 列 s, t の任意の半開区間同士の編集距離を答える。挿入、削除、置換のコストは各 1 である。
- 入力列を更新するには作り直す必要がある。
- 決定的な LCE を使うので、ハッシュの衝突は起きない。

## 構築

- 文字列か、const な size() と添字アクセスを持つ列を受け取る。
- 要素の < は、等値比較と整合する狭義弱順序 (strict weak ordering) である必要がある。
- |s|+|t|+1 <= INT_MAX が必要である。超える場合は length_error を送出する。
- 構築後は元の列を変更しても破棄してもよい。
- N = |s|+|t|+1 とする。要素の比較と添字アクセスが O(1) なら、前処理は O(N log N) 時間・空間である。
- s と t の要素を合わせて座標圧縮し、1 以上の値にする。0 は s と t の区切り専用にする。

## クエリ

- distance は距離 d に対して O((d+1)^2) 時間、O(d+1) 作業空間である。
- distance_bounded と within は、k >= 0 のとき O((k+1)^2) 時間、O(k+1) 作業空間である。
- within は、k が両区間の長さの最大値以上なら距離を計算せずに true を返す。

## bounded_impl

- prev[d] は、編集回数を固定したときに、対角線 d = x-y 上で一致部分を進み終えた最も遠い x である。添字は prev_l だけずらして持つ。
- LCE が指定された区間の外まで続いても、区間の端で打ち切る。
- 残りの編集回数で終点の対角線へ戻れない状態は除く。
- 端を越える遷移は、同じ対角線上の端へ切り詰める。これで「高々 cost 回」で到達できる最遠点を保つ。

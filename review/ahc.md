## kmeans.cpp

- **[注意]** `fit()` の反復中にクラスタが空になると `mean(空vector)` を呼び出します。ユーザーが実装する mean によっては 0 除算や UB になります。fit_flow には空クラスタの分岐がありますが、fit にはありません。
- **[注意]** k-means++ 風の初期化の重みが `p_f[i] = min_d + 1` で、型が `vector<int>` です。これには次の 2 つの問題があります。
  - 距離の 2 乗でなく距離 + 1 を重みにしており、遠い点を優先して選ぶという k-means++ の性質が弱くなっています。
  - DistType が double の場合は int へ切り捨てられます。距離がすべて 1 未満の場合は全点の重みが 1 になり、一様ランダムな選択になります。
- **[注意]** X の相異なる値の個数が k 未満の場合は `assert(flag)` で停止します。重複の多い入力では発生し得ます。
- **[軽微]** fit(X) と fit_flow(X, target_sizes) の初期化のコード全体が重複しています。
- **[軽微]** fit_flow の空クラスタの処理は、中心を直前の値でなく `init_centers[j]` に戻します。cluster_centers.clear() で直前の値が失われているためです。
- **[軽微]** `if (!changed && _ > 0)` の `_ > 0` は、labels の初期値が -1 で初回は必ず changed になるため冗長です。
- 計算量は意図どおりです。fit は O(max_iter·n·k) で、fit_flow は反復ごとに n·k 辺の MCF を構築します。
- 上記の問題は kmeans_new.cpp で解消されています。両方を残す場合は、ファイルの冒頭でこちらが旧版であると明記することを推奨します。

# titan_cpplib/ds/dycone.cpp 計算量解析

対象は `OfflineDynamicConnectivity`。コードから直接同定・解析した結果をまとめる。

## 結論

- **1 クエリあたり償却・期待 O(log n)**、`run()` 全体で **期待 O((n + q) log n)**。
- 期待値は乱数順列 `rd` についてのもの。クエリ列は任意でよい。
- 最悪ケースは 1 操作 O(n)、全体 O(qn)。この確率は指数的に小さい。
- 空間は O(n + q)。

## アルゴリズムの同定

オフライン動的連結性。方針は次の通り。

- 全クエリを先読みし、各辺に **重み W = −(削除時刻)** を与える。削除されない辺は −INT_MAX。
- **W に関する最小全域森**（= 削除時刻に関する最大全域森）を維持する。辺追加時に閉路上の最大重み辺と比較して差し替える（`inner_add_edge`）。この森では「時刻 t で u, v が連結 ⟺ 森の生存辺だけで連結」が成り立つ。
- 森そのものは持たず、**併合履歴を圧縮した根付き森**で表す。各ノード u は親 P[u] と親辺重み W[u] を持ち、根は番兵 W = 1。`rd` はランダム優先度で、併合時にどちらの代表が親になるかを決める。

P, W の森は全域森そのものではなく、**Kruskal 木（併合履歴の laminar 族）の圧縮表現**である。レベル w のクラスタ C(x, w) を「重み ≤ w の森辺だけで x と連結な頂点集合」とすると、`find(x, w)` は C(x, w) の代表を返す。全操作のコストはこの森の**経路長**で決まる。

## 構造不変条件

正当性と計算量の両方に使う。いずれもリンク生成箇所（`sub_add` の接続、`find`/`sub_del` の短絡、切断）に関する帰納法で示せる。

**I1（単調性）** 圧縮済みの状態では、任意ノードから根への経路上で W は狭義に増加する。`find` の内側ループ `while (W[P[u]] <= W[u])` は違反を見つけ次第、恒久的に短絡して回復する。

**I2（rd ヒープ性）** 全ての非根 y で rd[P[y]] > rd[y]。

証明: 接続時は `if (rd[u] < rd[v]) swap` により rd の大きい側が親になる。短絡 P[y] ← P[P[y]] は rd[P[P[y]]] > rd[P[y]] > rd[y] より保存。切断は辺を消すだけ。W の書き換えは辺の向きを変えない。∎

**I3（代表 = rd 最大）** 任意時点・任意レベル w で、find(x, w) は C(x, w) の **rd 最大ノード**を返す。

証明: 到達可能性（C(x, w) の全メンバーから同じノードに到達すること）は併合・切断の帰納による。I2 より経路上で rd は増加するから、到達先は全メンバーより rd が大きく、かつメンバー自身である。∎

**I4（部分木集約）** sum[x], sz[x] はポインタ森における x の部分木の総和。短絡・接続・切断のたびに差分修正され、`disconnect`/`connect` は併合中の一時的な取り外しと再装着を行う。

計算量に効く構造的事実を一つ加える。

**事実 D（削除は常に最大レベル）** 正規の削除（`inner_delete_edge`）が切る辺は、その時点でその成分内の**最大重み**を持つ。

証明: 時刻 t で削除される辺の重みは −t。生存中の他の辺は削除時刻が t より後だから重みは −t 未満。∎

切断されるノード c は成分のチェーン最上部にあり、subtree(c) がちょうど分離される側と一致する。これは正当性（どちら側に付くかの曖昧さがない）と、後述の「stale なリンクが削除では生じない」ことの両方を保証する。差し替え（`inner_add_edge` の replace）では中間レベルを切るが、直後に低いレベルで再結合されるため、レベル ≥ 切断点のクラスタは集合として変化せず問題ない。

## 主定理: 経路長の期待値

**定理 1** 任意の時点、任意のノード x について、圧縮済み経路の長さ L は E[L] ≤ 1 + ln n を満たす。期待値は一様ランダム順列 rd に関する。

証明: クエリ列はオフラインで固定されており、最小全域森は辺重みだけで決まる。−INT_MAX の同点も「厳密不等号のときだけ差し替え」により到着順で決定的に解消される。よって任意時点のクラスタの入れ子列

    C_0 = {x} ⊆ C_1 ⊂ C_2 ⊂ … ⊂ C_k （k ≤ n − 1）

は **rd と独立に決まる**。I1 と I3 より、x の圧縮済み経路が訪れるノードは各レベルの代表、すなわち argmax_rd C_i であり、経路長は列 (argmax C_i) の値の変化回数 + 1 に等しい。代表が変わらないレベルの併合では、負けた側のノードが**側枝**として付くだけで x の経路には乗らない。

argmax C_i が argmax C_{i−1} と異なる確率は、rd が一様順列であることから

    P[argmax C_i ∈ C_i \ C_{i−1}] = (|C_i| − |C_{i−1}|) / |C_i|

t = |C_{i−1}|/|C_i| に対する不等式 1 − t ≤ ln(1/t) より、各項は ln(|C_i|/|C_{i−1}|) 以下。総和は望遠鏡和になり

    E[L] ≤ 1 + Σ ln(|C_i|/|C_{i−1}|) = 1 + ln|C_k| ≤ 1 + ln n ∎

オフラインであることが本質で、敵対者は rd に適応してクラスタ列を選べない。オンラインで同じ構造を使うと、この証明は成立しない。

## 操作ごとのコスト

len を触れたノードの現在の経路長とする。定理 1 より期待 O(log n)。

| 操作 | 内部処理 | コスト |
|---|---|---|
| ADD（森に追加） | `max_edge` + `sub_add` | O(len_u + len_v) |
| ADD（差し替え） | 上に加え `sub_del` ×2 | O(len) |
| DEL | `sub_del` ×2 | O(len) |
| ADD_POINT | 経路を根まで歩く | O(len)（圧縮なし、後述） |
| GET_SUM / GET_SIZE / IS_SAME | `find` | O(len) |
| GET_COUNT | 変数参照 | O(1) |

個別に確認が要る点は二つ。

- **併合ループの反復回数**: `sub_add` のループは 1 反復につきちょうど 1 ノードを付け替え、二本のチェーンを重み順にマージする。二つの走査ポインタは単調に上昇するので、各チェーンのノードは高々 1 回しか付け替えられない。よって反復回数 ≤ len_u + len_v。`connect` の登りも併合全体で各辺を 1 回しか通らず、望遠鏡和で O(len_u + len_v)。
- **`sub_del`**: 事実 D より正規削除の対象はチェーン最上部にあり、登り + 切断後の集約修正で O(len)。森にない辺の削除要求は経路を空振りで登り切るだけで、やはり O(len)。

## 経路圧縮の償却

短絡（`P[u] = P[P[u]]`）は 1 回 O(1) で、rd[P[u]] を厳密に増加させる恒久的な変更である。短絡の対象になる「stale なリンク」の出所は一箇所しかない。

- `sub_add` で降格されたノード v（W[v] が旧値から併合レベル w に下がる）の**側枝の子** y のうち、W[y] ∈ (w, 旧 W[v]) のもの。y から見ると親が自分より低いレベルに落ちたため、次の `find` 系走査で 1 回の短絡により除去される。
- 正規の削除は事実 D により最大レベルを切るので、stale を作らない。

stale 対 1 つの解消コストは O(1) で、生成は併合の付け替え（期待 O(log n) 回/併合）に伴うものに限られる。各ノードの子の親辺重みは相異なるため、1 回の降格が作る stale 対の数は該当区間のレベル数で抑えられる。この会計から、`find` 系の走査が混ざる通常のクエリ列では短絡コストは償却 O(1)/クエリに収まり、全体の期待 O((n + q) log n) が得られる。

## 証明の範囲と注意点

- **厳密に証明した部分**: 定理 1、I1〜I4、事実 D、短絡を除く各操作コスト = 経路長、併合反復回数の上界。
- **スケッチに留まる部分**: stale 対の生成総数の期待評価は、rd に関する条件付けの独立性を厳密に処理していない。粗く抑えると期待 O(q log² n) の上界になり、実際上は O(q log n) 程度と考えられる。
- **`inner_add_point` は圧縮しない**: 根まで歩くだけで短絡を行わないため、`add_point` だけが長く続くワークロードでは同じ stale ノードを繰り返し踏み得る。`find` と同形の短絡（`sum[P[u]] -= sum[u]` を伴う付け替え）をここに入れれば、この隙間は閉じる。集約の辻褄は `find` の短絡と同じ形で合う。
- **シード固定**: `rd` は `mt19937(1321312)` で決定的にシャッフルされる。定理 1 の前提は rd の一様ランダム性なので、シードを知る敵対者は原理的には退化入力を構成できる。理論保証どおりに使うならシードを実行時乱数にする。
- **呼び出し順への依存**: `sub_add` 内の `find` は `disconnect` 後に呼ばれるが、直前の `max_edge` が両経路を清掃済みのため短絡が発火せず、集約の二重減算が起きない。この順序を変えると sum が壊れる。
- 前処理（`add_edge` 等のバッファリング）は `unordered_map` 込みで平均 O(1)/クエリ。

## まとめ

この構造は「削除時刻を重みとする最大全域森」を、rd をランダム優先度とする圧縮併合森で管理する。オフライン性を使って任意時点の経路長の期待 O(log n) が厳密に証明できる。これが全操作のコストを支配し、全体で期待 O((n + q) log n) になる。標準的な undo 付き DSU + 時間セグメント木の O(q log q log n) と比べ、log が一つ落ちる。

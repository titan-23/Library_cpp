# Wavelet Matrix 上の二分探索

## 実装の確認結果 (2026-09-03)

既存の本文を参照する前にソースを確認し、その後で記述と実装を照合しました。値域を直接降下する考え方は成立しますが、公開仕様には判定条件の単調性に加えて次の項目を含める必要があります。

- 重みの非負性
- 空区間
- k と目標値の定義域
- `sigma` が値域に含まれない上端であること

これらを `assert` だけで確認する場合、`NDEBUG` の指定時には不正な添字や意味のない境界値が使用されます。

特に、重み付き分位点の内部の補助関数は分子と分母を先に重みの型 W へ変換します。表現できる値の範囲が狭い W では、分母が 0 になるか、閾値が切り捨てられます。`total*numerator/denominator` は、積の桁あふれも避けることができる広い中間型を使用するか、商と剰余に分けて確認しながら計算するようにします。非負のキーを扱う固定ビット幅版の `range_freq` は、検索の上端が 0 以下なら 0 を、`2^log` 以上なら全件を返す必要があり、これらの場合にビットの走査を実行してはなりません。

性能面では、親区間で得た 0 側の順位から 1 側の区間を差分で導くことができます。`topk` と境界探索では、同じビット列へ `rank0` と `rank1` を別々に問い合わせず、両方を一度に返す基本処理にまとめるようにします。以下の本文は理論の説明として維持します。

## 対象

この文書では wavelet matrix を使用した二分探索を説明します。対象は「配列の添字」ではなく「キーの値順」に対する探索です。実装は [`wavelet_matrix_sum.cpp`](../titan_cpplib/ds/wavelet_matrix_sum.cpp) の `WaveletMatrixSum<T, W>` です。API の設計の経緯は [`wavelet_matrix.md`](wavelet_matrix.md) の 4.5 節に記載しています。

記号は次のとおりです。

- `n`: 配列長
- `σ`: キーの値域 `[0, σ)` の上端
- `L`: `ceil(log2(σ))`

## 前提: 区間の降下

wavelet matrix は、キーを上位ビットから 1 ビットずつ安定分割した `L` 段のビット列を保持します。段 `bit` では、区間 `[l, r)` の要素は次の 2 つの子区間に分かれます。

- 0 側: 現在のビットが 0 の要素からなる区間 `[rank0(l), rank0(r))`
- 1 側: 現在のビットが 1 の要素からなる区間 `[mid + (l - rank0(l)), mid + (r - rank0(r)))`

`mid` はその段全体に含まれる 0 の個数です。実装では `_v[bit].rank0` と `_mid[bit]` がこれらに対応します。

この変換には次の性質があります。

- 上位ビットが等しい要素のうち、0 側は値が小さい半分に、1 側は値が大きい半分に対応します。
- 各子区間の要素数は `rank0` の差から `O(1)` で求まります。
- 段ごとに 0 側の重みの累積和 `_zero_sum` を保持すると、各子区間の重みの総和も `O(1)` で求まります。

最上位ビットから最下位ビットまで降下すると、区間は同一キーの要素だけからなる区間になります。

## 二分探索としての見方

各段で 0 側と 1 側のどちらへ進むかを選ぶことは、値域を半分に絞る判定 1 回に相当します。`L` 段でキーが 1 つに定まります。

したがって、値域 `[0, σ)` に対する二分探索は、判定関数を外部から呼び出す代わりに wavelet matrix の降下として実行できます。判定に必要な子区間の要素数と総和が各段 `O(1)` で得られるため、探索全体の計算量は `O(L)` です。

## 2 つの方式

| 方式 | 内容 | 計算量の目安 |
|---|---|---:|
| 外側の二分探索 | `range_count` や `sum_lt` を判定関数とし、`k` や `value` を外側で二分探索する | `O(L log n)` または `O(L^2)` |
| 直接降下 | 各段で子区間の要素数と総和を参照し、進む子区間をその段で決定する | `O(L)` |

値順に関する単調な探索では直接降下を使用します。外側の二分探索が必要になるのは、後述の「値順で表現できない探索」に限られます。

## 実装例

### 個数を条件とする降下: `kth_smallest`

区間 `[l, r)` で昇順に `k` 番目のキーを求めます。最も単純な例です。

- 0 側の個数 `count0` を求めます。
- `k < count0` なら答えの現在のビットは 0 であるため、0 側へ降下します。
- `k >= count0` なら答えの現在のビットは 1 であるため、`k -= count0` として 1 側へ降下します。

判定の内容は「`k` 番目の要素が現在の値域の下半分にあるか」です。この判定は `rank0` の 2 回の呼び出しで完了するため、ソートせずに `O(L)` で `k` 番目のキーが求まります。

### 境界値に沿った降下: `range_freq`, `count_sum_lt`

`upper` 未満のキーの個数や総和を求めます。探索ではなく境界値が与えられる場合ですが、降下の方法は同じです。

- `upper` の現在のビットが 1 なら、0 側の子区間は全要素が `upper` 未満です。その個数と総和を加算し、1 側へ降下します。
- 0 なら 0 側へ降下します。

「子区間の全体を採用して反対側へ進む」という処理は次の探索でも使用します。

### 総和を条件とする降下: `min_count_smallest_sum_ge`

キーの昇順に要素を採用し、重みの総和が `target` 以上になる最小の個数を求めます。これは segment tree の `max_right` を、配列の位置順ではなく値順に行う操作に相当します。内部の実装は `_min_count_sum_ge` です。

各段の処理は次のとおりです。

- 0 側の総和 `sum0` を累積和から `O(1)` で求めます。
- `sum0 >= target` なら境界は 0 側の中にあるため、0 側へ降下します。
- `sum0 < target` なら 0 側の全要素の採用が確定します。`result += count0`, `target -= sum0` として 1 側へ降下します。

最下段で同一キーの区間に到達したら、そのキーを何個採用するかを `_leaf_min_count` で決定します。

- `weight = key` の場合は区間内の重みがすべて等しいため、個数は `ceil(target / key)` の除算で求まります。全体の計算量は `O(L)` です。
- 一般の重みの場合は、安定分割後の累積和 `_leaf_sum` に対して `lower_bound` を実行します。全体の計算量は `O(L + log n)` です。

この探索は値順の累積和が単調であることを前提とします。そのため重みは非負に限定します。負の重みを許容すると、子区間の総和だけでは「子区間の途中で一度 `target` に達したか」を判定できません。

### 個数を指定した総和の取得: `sum_k_smallest`

昇順で先頭 `k` 個の重みの総和を求めます。内部の実装は `_sum_k` です。

降下は `kth_smallest` と同じで、`k <= count0` なら 0 側へ、そうでなければ `sum0` を答えに加算して 1 側へ降下します。個数を条件とする降下と総和を条件とする降下は同じ処理の変種です。

### 候補の子区間が高々 1 つの探索: `has_majority`

区間の過半数を占めるキーの有無を判定します。

過半数を占めるキーが存在するなら、各段でその要素は片方の子区間に過半数のまま残ります。よって過半数の要素を含む子区間を選び続けると、候補を 1 つに絞ることができます。どちらの子区間も過半数に満たない段があれば、その時点で存在しないことが確定します。

## 直接降下が成立する条件

次の条件がすべて成り立つ場合に直接降下を使用できます。

- **探索の軸が値順です。** 個数 `k` や境界キーの探索は各段の子区間で表現できます。元の配列上の位置の探索は各段で表現できないため、`count_range(l, mid, lower, upper)` などを判定関数とする外側の二分探索になります。
- **述語が値順に単調です。** `max_right` と同様に、一度偽になったら偽のままである必要があります。累積 XOR のように真偽が何度も入れ替わる条件には使用できません。
- **子区間の集約値が段ごとに低コストで得られます。** 総和なら段ごとの累積和で十分です。`min`, `max`, `gcd` では段ごとに RMQ などの構造が必要であり、総和用の累積和では代用できません。

## 計算量

静的な総和付き wavelet matrix での比較を示します。

| 方法 | 計算量 |
|---|---:|
| 値順に直接降下する | 一般の重みは `O(L + log n)`、`weight = key` は `O(L)` |
| `k` を外側で二分探索する | `O(L log n)` |
| `value` を外側で二分探索する | `O(L^2)` |
| 元配列上の位置を外側で二分探索する | `O(L log n)` |
